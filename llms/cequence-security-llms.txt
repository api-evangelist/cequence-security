# Cequence AI Gateway

> Enterprise AI Gateway making applications agent-ready through secure MCP integration.

Cequence AI Gateway enables enterprises to safely connect AI agents to business applications using the Model Context Protocol (MCP). It provides enterprise-grade security, OAuth authentication, comprehensive monitoring, and zero-trust architecture for agentic AI productivity.

## Getting Started
- [Introduction](https://docs.aigateway.cequence.ai/docs/introduction): Overview of AI Gateway capabilities and architecture
- [Getting Started](https://docs.aigateway.cequence.ai/docs/getstarted): Quick start guide for launching your first MCP server
- [Administration](https://docs.aigateway.cequence.ai/docs/administration): Administrative configuration and management
- [Agent Personas](https://docs.aigateway.cequence.ai/docs/agent-personas): Build AI agents that combine tools from multiple MCP servers into a single endpoint with SSO and access key authentication
- [Teams](https://docs.aigateway.cequence.ai/docs/teams): Control access to MCP servers and Agent Personas using SSO group-based teams
- [Skill Registry](https://docs.aigateway.cequence.ai/docs/skill-registry): Register reusable Agent Skills (SKILL.md) that agents discover and load on demand, and attach them to Agent Personas
- [API Registry](https://docs.aigateway.cequence.ai/docs/api-registry): Register REST APIs from their OpenAPI specs so agents can call selected endpoints through the gateway with governed authentication, DLP, rate limiting, and audit
- [Private Cloud Deployment](https://docs.aigateway.cequence.ai/docs/private-cloud-deployment): Deploy the AI Gateway Operator and Armor gateway to your Kubernetes clusters, including cell-based isolation (Critical / Standard / Experimental tiers) for blast-radius separation
